# Access Control

This directory contains reports for Access Control vulnerabilities from PortSwigger Web Security Academy.

The labs cover common authorization flaws and techniques used to bypass access controls.

## Topics Covered

- Unprotected Administrative Functionality
- Unprotected Admin Functionality with Unpredictable URL
- User Role Controlled by Request Parameters
- User Role Manipulation
- Insecure Direct Object Reference (IDOR)
- Path Traversal
- Access Control Bypass
- URL-based Access Control
- Method-based Access Control
- Multi-step Access Control Vulnerabilities

Each lab contains a complete vulnerability report, including:

- Summary
- Impact
- Steps to Reproduce
- Proof of Concept (PoC)
- Evidence
- Vulnerability Classification
- Remediation
